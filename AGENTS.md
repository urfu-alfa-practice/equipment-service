# Работа над проектом

Это небольшой учебный проект: FastAPI, SQLite из стандартной библиотеки, Jinja2 и HTML/CSS.
Поддерживаем Python 3.11+. Интерфейс и документация — на русском, имена в Python — на английском.

- Прочитай README и относящийся к задаче код. Уточни неоднозначные требования и предложи план.
- Если пользователь просит только план, не меняй файлы. После поручения на реализацию выполни его.
- Сохраняй минимальный стек. Внешние сервисы, Node.js, Docker и ORM для базовых задач не нужны.
- Общая валидация находится в `app/models.py`, SQL — в `app/repository.py`.
- Существующие данные должны сохраняться. Изменение CREATE TABLE не обновляет старую таблицу:
  при изменении схемы продумай и проверь обновление существующей базы.
- Не добавляй приоритеты, фильтры и другие учебные доработки без соответствующего задания.
- Параметризуй SQL. Не отключай экранирование пользовательского текста в шаблонах.
- Даты хранятся в UTC с часовым поясом. Время создания при смене статуса не меняется.
- Для изменения поведения добавляй осмысленные тесты, в том числе на ошибочный ввод.
- Выполни `python -m pytest`, `python -m ruff check .`, `python -m ruff format --check .`
  в виртуальном окружении. Сообщи, какие проверки действительно выполнены.
- Не включай базу, виртуальное окружение, ключи и кэши в коммиты.
